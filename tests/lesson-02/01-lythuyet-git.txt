1. Giải thích câu lệnh:
- git init: Khởi tạo thư mục được quản lý bởi git
- git add <file_name>: thêm <file_name> vào môi trường staging (working directory) => vào khu vực chuẩn bị commit trong Git
- git add .: add tất cả các file vào môi trường staging (working directory)=> vào khu vực chuẩn bị commit trong Git
- git commit -m "message": commit code vào vùng staging area
