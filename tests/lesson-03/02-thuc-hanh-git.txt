2. Liệt kê các file theo từng vùng:
a. Tạo 3 file: file1, file2, file3
- Working directory: file1, file2, file3
- Staging area: chưa có gì 
- Repository: chưa có gì 

b. Chạy lệnh [git init]=> khởi tạo 1 kho lưu trữ mới trong folder lesson-3
- Working directory: file1, file2, file3
- Staging area: chưa có gì 
- Repository: chưa có gì 

c. Chạy lệnh [git commit -m "init project"] =>commit thay đổi từ staging area vào Repository. Tuy nhiên staging area trống nên không có tác dụng đáng kể
- Working directory: file1, file2, file3
- Staging area: chưa có gì 
- Repository: có commit đầu tiên là "init project" nhưng chưa có file nào

d. Chạy lệnh [git add file1] => thêm file1 vào staging area
- Working directory: file1, file2, file3
- Staging area: file1
- Repository: có commit đầu tiên là "init project" nhưng chưa có file nào


e. Chạy lệnh git commit -m "add file1" =>commit file1 từ staging area sang repository
- Working directory: file1, file2, file3
- Staging area: trống
- Repository: có commit đầu tiên là "init project" và file1

f. Chạy lệnh [git add .]=> thêm tất cả file có thay đổi vào staging area
- Working directory: file1, file2, file3
- Staging area: file2, file3
- Repository: có commit đầu tiên là "init project" và file1

g. Chạy lệnh [git restore --staged file2]=> muốn bỏ file2 từ staging area => working directory
- Working directory: file1, file2, file3
- Staging area: file3
- Repository: có commit đầu tiên là "init project" và file1

h. Chạy lệnh [git commit -m”add all files]=> commit file3 từ staging area sang repository
- Working directory: file1, file2, file3
- Staging area: trống
- Repository: có commit đầu tiên là "init project", file1 và file3

i. Chạy lệnh [git reset HEAD~1]=> reset 1 commit là commit ở "h"
- Working directory: file1, file2, file3
- Staging area: trống
- Repository: có commit đầu tiên là "init project", file1
